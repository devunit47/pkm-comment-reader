ぽこめ Reader は移転しました

このページで公開していたブラウザ版は終了しました。今後は、PCで動かすローカル版（Windows配布版）として提供します。

移転した理由

  • OBSへの取り込みや音声ソフト（VOICEVOX・COEIROINK）との連携、PCのフォルダーからの素材の読み込みなど、ローカル版でしか使えない機能が増え、ブラウザ版との差が大きくなったためです。
  • YouTube・Kickなど今後追加したいサービスへの接続には、PC上で動くサーバーが必要になります。ブラウザ版のままでは対応できないためです。

入手方法と使い方は、GitHubのページをご覧ください。

GitHub の ぽこめ Reader のページを開く

このページで保存した接続先・音声・見た目などの設定は、新しい版には引き継がれません。新しい版で設定し直してください。
